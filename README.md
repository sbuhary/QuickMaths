# MathSprout

MathSprout is a mobile-first arithmetic practice app for children. It runs as a static website and can be hosted directly on GitHub Pages.

## Features
- Addition, subtraction, multiplication, and division.
- Starter, Explorer, and Wizard difficulty levels.
- Writable whiteboard with pen colors, eraser, undo, and clear.
- Timer per question. Timer can cycle between digital, analog, and hourglass styles.
- Answer checking from the written answer box using local canvas-based digit recognition, with browser handwriting recognition as an optional fallback.
- Separate level/options screen with stars, streaks, and locked level progression saved on the device.

## Run Locally
Open `index.html` in a browser.

## Host On GitHub Pages
1. Push this repository to GitHub.
2. In the repository settings, open Pages.
3. Set the source to the default branch and root folder.
4. Save and open the published Pages URL.
